# Simple Cooking Tooltip

Cooking ingredient tooltip helper for **World of Warcraft: Forever**.

Hover an ingredient to see where to farm it and which Cooking skill you need before a recipe using it becomes available.

## Features

- Up to three main areas per ingredient, most drops first
- The Cooking skill level at which a recipe using the ingredient is learned
- Vendor-sold staples marked as such
- Slash `/sct` for status
- Feature flags to turn tooltip lines on or off

## Install

1. Install via CurseForge / your preferred client, **or** copy the `simple-cooking-tooltip` folder to:

   `World of Warcraft\_forever_\Interface\AddOns\simple-cooking-tooltip`

2. Restart the client or log out and back in.
3. Enable **Simple Cooking Tooltip** on the character addon list if needed.

**Requires Forever** (`Interface` 16001 / 1.60.x). Not for Classic Era or Retail.

## How to use

Hover any cooking ingredient (meat, fish, eggs, spices, ...) in your bags, on the auction house, or in a loot window.
