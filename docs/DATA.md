# Recipe data

[`Data/Recipes.lua`](../simple-cooking-tooltip/Data/Recipes.lua) is generated by [`scripts/gen-recipes.py`](../scripts/gen-recipes.py). `[spellId] = { name, skill, learn, faction?, reagents }`:

- `skill`: Cooking skill at which the recipe is learned (Forever value).
- `learn`: `"trainer"` (trainer, or learned with the skill) or `"item"` (taught by a recipe item: vendor, drop or quest).
- `faction`: `"Alliance"` or `"Horde"` when only that faction can learn it; omitted means both.
- `reagents`: reagent item ids. The ingredient -> recipes index is built at load in `Ingredients.lua`.

Ordering on the tooltip: trainer before item, then lowest skill, then name; at most 5 shown.

[`Data/Sources.lua`](../simple-cooking-tooltip/Data/Sources.lua) maps reagent item id to `sources = { { mobOrObject, zone, faction? }, ... }` (up to three, most drops first) and `vendor = true` when vendors sell it. A source carries `faction` when its zone belongs to one faction only (see `ZONES` in the generator) and is hidden from the other faction. Sources cover 91 of 113 reagents; the rest (some herbs and juices, Simple Flour, and Forever-only items such as Hyjal Berries, Whimsyfin and Thick Logs) show recipes only.

## Provenance

Generated 2026-11-24 from saved pages (kept in git-ignored `data-src/`):

| File | Source | Used for |
| --- | --- | --- |
| `bbb-cooking-recipes.psv` | Booty Bay Broker Forever recipe list API | All 132 recipes: spell id, name, skill, trainer or recipe item |
| `bbb-forever-reagents.json` | Booty Bay Broker per-recipe cost API | Reagents of the 44 Forever-only recipes |
| `wowhead-classic-cooking.html` | Wowhead Classic Cooking spell list | Reagents of the 88 recipes that also exist in Classic (matched by spell id) |
| `ingredient-zones.lua` | Old `Data/Ingredients.lua` from git history (`git show 6759b6e:simple-cooking-tooltip/Data/Ingredients.lua`), from Wowhead Classic | Ingredient sources and zones |
| `classic-sources.json` | `scripts/crawl-wowhead-sources.py` (Wowhead Classic spell pages) | Faction of recipe items/quests |

Booty Bay Broker blocks automated requests, so those files were saved from a browser; terms of reuse of that site's data have not been reviewed. Wowhead: keep > 2.5 s between requests and stop on 403.

## Known gaps

- **Faction is partly inferred.** Order of evidence: (1) the recipe item or quest side from the Wowhead crawl (2 recipes: Beer Basted Boar Ribs Alliance, Scorpid Surprise Horde; the crawl stopped at 50 of 89 pages, HTTP 403); (2) for recipes taught by an item only, the zones of the old ingredient source lists (`data-src/ingredient-zones.lua`, from git history): a recipe is bound to a faction when one of its ingredients is found only in that faction's starting zones and none is bound to the other (15 recipes, all Alliance so far). This is a heuristic: those lists hold only the top three sources per ingredient, and contested zones (The Barrens, Duskwood, Hillsbrad, ...) never bind a faction. Trainer recipes and the holiday recipes (Gingerbread Cookie, Egg Nog) are never inferred. Everything else shows to both factions.
- Vendor, drop and quest are not distinguished yet.
- Reagents of the 88 Classic-matched recipes come from Classic and may differ in Forever.
- Not verified in game.
- Regenerate: `python -I scripts/crawl-wowhead-sources.py` (resumes), then `python -I scripts/gen-recipes.py`.
